🔑 Chave API do YouTube
Como obter (gratuito):
  1. Acesse console.cloud.google.com com sua conta Google
  2. Crie um novo projeto (ex: "Prospector MCMV")
  3. No menu lateral vá em APIs e Serviços → Biblioteca
  4. Busque "YouTube Data API v3" e clique em Ativar
  5. Vá em APIs e Serviços → Credenciais → Criar credencial → Chave de API
  6. Copie a chave gerada e cole abaixo

Cota gratuita: 10.000 unidades/dia — suficiente para centenas de buscas.
